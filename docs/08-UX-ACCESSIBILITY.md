# 08 — Interfaz y accesibilidad

La web funciona como una herramienta directa de generación, no como un sitio de marketing.

- Un formulario selecciona uno de los nueve tipos de contenido.
- Los campos tienen etiquetas, ayuda y errores visibles.
- El selector de tipo admite teclado y la interfaz publica el estado de validación con `aria-live`.
- El panel de vista previa presenta SVG generado por la API.
- Descarga permite SVG, PNG o GIF; el botón permanece deshabilitado hasta recibir una validación válida.
- No hay registro, navegación de producto ni persistencia del formulario.
- La vista se adapta a móvil y escritorio sin esconder campos esenciales.

La apariencia debe seguir simple y priorizar legibilidad, contraste y estados claros sobre secciones promocionales.
