# Definition of Done

## Alcance

- [ ] El cambio corresponde al generador QR estático.
- [ ] La documentación vigente describe el comportamiento.
- [ ] No se introduce una capacidad fuera de alcance sin decisión nueva.

## Implementación

- [ ] TypeScript estricto y contratos compartidos.
- [ ] Validación autoritativa en la API.
- [ ] Errores HTTP controlados y sin datos sensibles en logs.
- [ ] No hay código muerto ni dependencia sin justificar.

## QR y experiencia

- [ ] Payload canónico correcto.
- [ ] Capacidad y contraste validados.
- [ ] Vista previa y descarga las genera la API con las mismas opciones.
- [ ] Estados de error, espera y descarga son accesibles.

## Calidad

- [ ] Pruebas unitarias, integración o E2E apropiadas al cambio.
- [ ] Formato, lint, tipos y build pasan.
- [ ] Configuración de ejemplo está actualizada.
